# 作品詳細画面

作品の詳細画面。

## 要素

| 要素 | 内容 |
|---|---|
| 作品の情報 | 作品名・副題・作品名読み・分類番号・文字遣い種別・初出・公開日・著作権 |
| 関係者 | 名前・役割・生没年 |
| 図書カード | 青空文庫の図書カードを開く |
| 読むボタン | 本文を表示する |

出すのは **DB が持っている範囲だけ**。足りないものは[図書カード](#図書カードへのリンク)に任せる。

**本文のファイルを持たない作品は読めない。** テキストも HTML も無い作品が 82 件ある。

関係者は**役割を問わず出す**。著者だけに絞らない。翻訳者を含む作品が 1,097 件ある。

生没年は片方だけ欠けることがある（生年が 75 人、没年が 175 人）。存命ではなく不明。

## 作品の取得

作品IDを受け取り、`GET /books/{bookId}` で取る。

## 未定

- 値を持たない項目を行ごと省くか、空のまま出すか（初出は 40% が空）
- 読むボタンを押したあとどうなるか（リーダーが未実装）
- 関係者をタップしたらどうなるか（その人の作品に絞れる）
- 分類番号をそのまま出すか（`NDC 913` の形で、番号の意味は DB に無い）
- 取得中・失敗したときに何を出すか

## 備考

### 図書カードへのリンク

本家の図書カードは、こちらの DB より多くを出している。

| 図書カードの節 | DB にあるか |
|---|---|
| 作品名・読み・著者名 | ある |
| 作品データ（分類 / 文字遣い種別） | ある |
| 作品データ（作品について / 備考） | **無い** |
| 作家データ（名前 / 読み / ローマ字 / 生没年） | ある |
| 作家データ（人物について） | **無い** |
| 底本データ（底本 / 出版社 / 初版発行日 / 親本） | **無い** |
| 工作員データ（入力 / 校正） | **無い** |
| ファイルの種別・サイズ・登録日 | URL のみ |

無いものは CSV に入っていない。取るには図書カードをスクレイピングすることになり、
17,717 件ぶんの取得と保存先が要る（`aozora_database.sqlite3` は
[再生成のたびに中身が入れ替わる](../technical/metadata-db.md)ので置けない）。

リンク 1 つで済ませる。

### 欠けている項目

| 項目 | 欠けている件数 |
|---|---|
| 初出 | 7,102（40%） |
| 分類番号 | 630 |
| 本文ファイル（テキスト） | 154 |
| 本文ファイル（テキストも HTML も） | **82** |
| 副題 | 14,903（副題を持つのは 2,814 件） |

人物のほうは、生年が 75 人、没年が 175 人ぶん欠けている。ローマ字は全員ある。

### 関係者の実情

1 作品に 1 人だけとは限らない。

| | 件数 |
|---|---|
| 関係者が 2 人以上 | 1,460 |
| 翻訳者を含む | 1,097 |
| 著者が 2 人以上 | 422 |

並びは role の**文字列順**なので、翻訳作品では「翻訳者」が「著者」より先に来る。
