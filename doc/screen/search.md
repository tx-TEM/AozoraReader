# 検索タブ

キーワードで作品を探す。

## 要素

| 要素 | 内容 |
|---|---|
| 検索入力 | キーワードを入力して送る |
| 検索結果 | 一致した作品の一覧 |

## 使う API

`GET /books?q=`

検索対象は作品名・作品名読み・人物名で、**本文は含まない**
（[メタデータ DB](../technical/metadata-db.md#検索条件の組み立て)）。
