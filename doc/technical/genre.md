# ジャンル

[カテゴリー](category.md)の中を分けたもの。分類番号の読み方はカテゴリーのほうに書いた。
ジャンルの中を分けたものが[サブジャンル](subgenre.md)。

## 決まり

ジャンルは NDC の**綱**（2 桁目まで）。1 つのジャンルは 1 つのカテゴリーに属する（`91` は `9` の中）。

分類番号を複数持つ作品（`NDC 913 914` など）は、当てはまるジャンルのすべてに入る。

**`K`（児童書）は無視する。** `K913` は `913` と同じく、ジャンル `91` 日本文学に入る。

**分類番号の無い作品は「その他」に入れる。**

| 項目 | 値 |
|---|---|
| ID | 綱の番号（`91`）。その他は `other` |
