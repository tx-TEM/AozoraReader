# カテゴリー

作品の大きな分け方。[メタデータ DB](metadata-db.md) の `ndc`（分類番号）から組み立てる。
カテゴリーの中を分けたものが[ジャンル](genre.md)。

## 分類番号

日本十進分類法（NDC）の番号。3 桁で、頭から 1 桁ずつ細かくなる。

| 段 | 桁 | 例 | 区切り |
|---|---|---|---|
| 類 | 1 桁目 | `9` 文学 | カテゴリー |
| 綱 | 2 桁目まで | `91` 日本文学 | [ジャンル](genre.md) |
| 目 | 3 桁目まで | `913` 小説・物語 | [サブジャンル](subgenre.md) |

`K` が頭に付いた番号は児童書（`K913` は児童書の小説）。段とは別の印。
`K` の付く作品は、持っている番号がすべて `K` 付き。

## 決まり

カテゴリーは**類**。

分類番号を複数持つ作品（`NDC 913 914` など）は、当てはまるカテゴリーのすべてに入る。

**`K`（児童書）は無視する。** `K913` は `913` と同じく、カテゴリー `9` 文学に入る。

**分類番号の無い作品は「その他」に入れる。**

名前は NDC 標準の類名、ID は類の番号。

| ID | 名前 |
|---|---|
| `0` | 総記 |
| `1` | 哲学 |
| `2` | 歴史 |
| `3` | 社会科学 |
| `4` | 自然科学 |
| `5` | 技術．工学 |
| `6` | 産業 |
| `7` | 芸術．美術 |
| `8` | 言語 |
| `9` | 文学 |
| `other` | その他 |
