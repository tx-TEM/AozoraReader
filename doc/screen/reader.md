## 本文の表示

本文は青空文庫が配っている **HTML をそのまま出す**。青空文庫記法のパースも、
組版の作り込みもしない。ルビは HTML に `<ruby>` で入っている。

開く先は **ホストを問わない**。138 件は青空文庫以外のサイトを指しているが、区別しない。

**どこまで読んだかは覚えない。** 開くたびに先頭から読む。

## 読めない作品

うち 11 件はテキストを持っているが、**テキストは読まない**ので同じ扱いにする。

## 備考

### HTML とテキストのどちらを読むか

本文は 2 通りで配られている。

| | 中身 | 持たない作品 |
|---|---|---|
| テキスト | ZIP に入った Shift_JIS。青空文庫記法（`｜漢字《かんじ》`） | 154 件 |
| HTML | XHTML。ルビは `<ruby>` タグ | 93 件 |

HTML はルビも組版も済んでいて、開けばそのまま読める。テキストのほうは ZIP の展開と
記法のパースが要る。自前で描くのは、縦書きや文字サイズを自由にしたくなってからでいい。
