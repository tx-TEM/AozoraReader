# サブジャンル

[ジャンル](genre.md)の中を分けたもの。分類番号の読み方は[カテゴリー](category.md)のほうに書いた。

## 決まり

サブジャンルは NDC の**目**（3 桁目まで）。1 つのサブジャンルは 1 つのジャンルに属する（`913` は `91` の中）。

分類番号を複数持つ作品（`NDC 913 914` など）は、当てはまるサブジャンルのすべてに入る。

**`K`（児童書）は無視する。** `K913` は `913` と同じサブジャンルに入る。

**分類番号の無い作品は「その他」に入れる。**

| 項目 | 値 |
|---|---|
| ID | 目の番号（`913`）。その他は `other` |
